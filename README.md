# Rahaf Portfolio

موقع شخصي عربي (RTL) يعرض رحلة رهف في علوم الحاسب، اهتماماتها التقنية، مهاراتها التي تتعلمها، مشاريعها، وطموحها المهني.

## التشغيل
1. حمّلي المجلد كاملًا.
2. افتحي `index.html` في المتصفح.
3. اتركي `style.css` و`script.js` في نفس المجلد.

## الملفات
- `index.html`: محتوى الموقع.
- `style.css`: التصميم والتجاوب.
- `script.js`: التفاعلات البسيطة.

الموقع لا يستخدم صور SVG أو يحتاج إلى تثبيت برامج.
