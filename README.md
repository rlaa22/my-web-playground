# My Web Playground — Rahaf

A responsive Arabic-first static website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — visual design, responsive layout, and light theme
- `script.js` — theme toggle, interactive JavaScript demo, CSS demo, and code-copy buttons

## Run locally
Open `index.html` in a browser. For clipboard support, use VS Code Live Server or another localhost server.

## Publish with GitHub Pages
1. Create a GitHub repository named `my-web-playground`.
2. Upload all three files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for the published URL to appear in the Pages section.
