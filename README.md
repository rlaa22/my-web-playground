# MY WEB PLAYGROUND — Rahaf

Arabic-first responsive web project built with HTML, CSS and JavaScript.

## Project files
- `index.html` — all required content and page structure.
- `style.css` — dark blue design, layout and responsive mobile styling.
- `script.js` — working JavaScript interactions.

## Run locally
Open `index.html` in a browser, or use Live Server in VS Code.

## Publish with GitHub Pages
1. Create a public repository named `my-web-playground`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch, branch `main`, folder `/ (root)`, then Save.
5. Wait for GitHub Pages to show the published URL.

Review and personalize the examples before submitting so you can explain what each part does.
