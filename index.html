STATION 03

HTML · BUILD THE STRUCTURE

HTML لغة ترميز تحدد محتوى الصفحة وعناصرها، مثل العناوين والفقرات والصور والروابط.

<h1>Hello, Web!</h1>
<p>This is my first page.</p>
النتيجة في المتصفح ←

Hello, Web!

This is my first page.

الفكرة: HTML تصف معنى ومحتوى العناصر، ولا تحدد وحدها شكل التصميم النهائي.

✳
STATION 04

CSS · STYLE THE PAGE

CSS تتحكم في مظهر عناصر HTML، مثل الألوان والخطوط والمسافات وتوزيع العناصر.

h1 {
  color: purple;
  font-size: 32px;
}

←
بعدHello, Web!

جرّبي تغيير قيمة اللون إلى orange أو hotpink ولاحظي كيف يتغير المظهر.

ϟ
STATION 05

JAVASCRIPT · MAKE IT INTERACTIVE

JavaScript لغة برمجة تضيف السلوك والتفاعل إلى الصفحة، مثل الاستجابة للضغط وتغيير النصوص والتحقق من المدخلات.

const button = document.querySelector("#demoBtn");
button.addEventListener("click", function () {
  document.querySelector("#demoText").textContent = "You did it!";
});
جرّب بنفسك

اضغط الزر لترى كيف تتغير هذه العبارة.

المهم: الكود يعمل فعلًا داخل الصفحة، وليس مجرد صورة توضيحية.

TWO SIDES OF THE WEB · 06

Frontend vs Backend

يمكن تقسيم عمل تطبيق الويب بصورة مبسطة إلى واجهة يراها المستخدم، وجزء خلفي يعالج البيانات والطلبات.

▱

Frontend

الجزء الذي يراه المستخدم ويتفاعل معه، مثل الأزرار والقوائم والنصوص والتصميم.

HTMLCSSJavaScript
واجهة المتجر
▤

Backend

الجزء الذي يعمل خلف الواجهة، ويتعامل مع منطق التطبيق والطلبات وقواعد البيانات.

ServerAPIsDatabase
REQUEST → RESPONSE
💡 مثال: عرض المنتجات وزر الشراء جزء من Frontend، أما التحقق من الطلب وحفظه واسترجاع بيانات المنتج فيتم عبر Backend. لا يتطلب التكليف بناء Backend فعليًا.
